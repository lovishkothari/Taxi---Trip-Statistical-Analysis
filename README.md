# Taxi Trip Statistical Analysis

##  Project Overview
Statistical analysis of taxi trip data using Python and Seaborn to identify trip patterns, fare behavior, payment methods, and time-based trends.

##  Objectives
- Analyze taxi trip patterns and distributions
- Study pickup and drop-off boroughs
- Analyze payment methods
- Examine trip activity by pickup hour
- Analyze fare, distance, and total amount
- Perform statistical and exploratory analysis
- Generate meaningful insights through visualizations

##  Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

##  Analysis Performed
- Data inspection and cleaning
- Descriptive statistics
- GroupBy & aggregation
- Pivot table analysis
- Univariate, Bivariate & Multivariate EDA
- Data visualization
- Statistical analysis
